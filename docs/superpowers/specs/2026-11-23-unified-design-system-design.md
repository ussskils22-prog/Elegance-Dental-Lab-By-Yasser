# توحيد ديزاين السيستم (خط Cairo + كروت ملوّنة خفيفة حسب المرحلة)

التاريخ: 2026-11-23

## الهدف وليه

السيستم مش شبه بعضه. فيه تلات خطوط متلخبطة، ولون Cairo مكتوب في 8 أماكن مع إن الخط نفسه مش متحمّل أصلًا. وفيه حوالي 1200 لون مكتوبين كأرقام في ملفات الشاشات، وكل شاشة بتلوّن الأرقام والشارات بطريقتها. والنتيجة إن الألوان مالهاش معنى: في الريسبشن مثلًا "الخارجة = 0" بتظهر بالأحمر.

الهدف إن السيستم كله يبقى شكله واحد على "اقتراح 3" اللي صاحب السيستم اختاره:
- **خط Cairo** في كل الشاشات.
- **كل مرحلة ليها لون ثابت** يتكرر في كل مكان، سواء كارت إحصائية أو فلتر أو شارة على الحالة. والكروت خلفيتها ملوّنة خفيف، بدل الأرقام الفاقعة.
- **التركواز (لون اللوجو)** هو اللون الأساسي للأزرار والفلتر المختار، بدل البنفسجي.
- **الوضع الفاتح** يفضل "ورق بيج دافي" زي ما هو (`#f3efe6`)، وياخد نفس فكرة الكروت الملوّنة الخفيفة.

## المطلوب (Goals)

1. خط واحد بس، Cairo، متحمّل صح من Google Fonts بالأوزان 400 و600 و700، ومتعرّف مرة واحدة كمتغير.
2. متغيرات ألوان للمراحل في `client/src/styles.css`، للغامق والفاتح.
3. كل ملفات CSS في الشاشات تستخدم المتغيرات بدل ألوان مكتوبة بإيدينا.
4. الأرقام الكبيرة تظهر بفاصلة آلاف (1,369)، بأرقام لاتيني زي دلوقتي.
5. اللون الأحمر يتساب **للمستعجل والمتأخر والخطأ** بس. الصفر والحاجات الطبيعية يبقوا رمادي.

## مش مطلوب (Non-goals)

- تغيير **مكان** أي حاجة على الشاشات. الترتيب الحالي باقي زي ما هو، لأن صاحب السيستم قال صراحة إن الترتيب الحالي أحسن.
- أي تغيير في الـ backend أو الـ workflow أو الحسابات.
- الإيصال والشيت اللي بيطلعوا من الطابعة (`print-agent`، وأي `@media print`).
- الإيجنتس (`print-agent` و`scan-agent` و`exocad-agent`).

## اللي لو حصل يبقى فشل (Anti-goals)

- شاشة تبقى مش مقروءة في وضع من الاتنين (غامق أو فاتح).
- لون مرحلة يبقى ليه معنى في شاشة ومعنى تاني في شاشة تانية.
- أي زرار أو فعل يبطل يشتغل بسبب تعديل في الـ HTML. المسموح هنا CSS، وفي الـ HTML تغيير classes بس.

## الطرق اللي اتعرضت

| الطريقة | المقابل |
|---|---|
| شاشة الريسبشن بس | صغيرة ومفيهاش خطر، بس السيستم هيفضل مش موحد |
| الخط للكل والكروت للريسبشن بس | وسط |
| **السيستم كله، على مراحل** ← **اللي اتختار** | أكبر شغل، بس هو الوحيد اللي بيحقق "موحّد" |

## التصميم

### 1. الخط
- `index.html`: نضيف Cairo (400;600;700) لرابط Google Fonts، ونشيل Tajawal.
- `styles.css`: نعرّف `--font-sans: 'Cairo', 'IBM Plex Sans Arabic', 'Segoe UI', system-ui, sans-serif;`، و`body { font-family: var(--font-sans); }`.
- أي `font-family` في ملفات الشاشات (Cairo أو IBM Plex أو Tajawal) يتشال أو يبقى `inherit`. الخطوط الـ monospace (الباركود ورقم الحالة) تفضل زي ما هي.
- الأوزان: 400 للنص، و600 للعناوين والأسماء، و700 لأرقام الإحصائيات بس.

### 2. ألوان المراحل
المراحل الموجودة في الكود (`casePhaseBadge`): `pending`، `design`، `khart`، `revision`، `finishing`، `finished`، `exited`، وفوقهم `urgent` (أولوية emergency والمتأخر).

كل مرحلة ليها 4 متغيرات: `--stage-<name>-bg` و`--stage-<name>-border` و`--stage-<name>-text` و`--stage-<name>-solid` (الأخير للنقطة والحافة).

| المرحلة | معناها | غامق bg / border / text | فاتح bg / border / text |
|---|---|---|---|
| pending (جديدة) | محايد | `#22252b` / `#2f333a` / `#c3c8cf` | `#efe8da` / `#e0d6c3` / `#57534e` |
| design | أزرق | `#172535` / `#203a57` / `#9cc4fb` | `#e6eefa` / `#c3d5ef` / `#1d4f8f` |
| khart | بنفسجي | `#221d36` / `#3a3160` / `#b8aef5` | `#eeebfa` / `#d4cdf2` / `#4b3f9e` |
| revision | مرجاني | `#2c1c16` / `#55301f` / `#f0997b` | `#fbece5` / `#f1c7b4` / `#993c1d` |
| finishing | أصفر | `#2a2213` / `#4a3a1a` / `#eec06c` | `#fbf0dc` / `#ecd3a3` / `#8a5a0b` |
| finished (جاهزة) | أخضر | `#13281f` / `#1d4433` / `#5fd6a0` | `#e6f3ea` / `#bfdcc8` / `#2f6b45` |
| exited (خرجت) | رمادي | `#1d1f23` / `#2a2d33` / `#8b929b` | `#ece7dd` / `#ddd5c6` / `#78716c` |
| urgent | أحمر | `#2e1717` / `#5a2626` / `#f87171` | `#fbe9e7` / `#f0c2bc` / `#b42318` |

قيمة `solid` لكل مرحلة هي نفس لون الـ text في الوضع الغامق، ونفس لون الـ border في الفاتح بس أغمق درجة. وده قرار للمنفّذ، طالما التباين واضح.

### 3. باقي المتغيرات
- نحافظ على المتغيرات الحالية (`--bg-primary` و`--text-*` و`--border-*` و`--accent-*`) بأسمائها، عشان مفيش حاجة تتكسر.
- `--accent-primary` (التركواز) هو لون الزرار الأساسي والفلتر المختار في كل الشاشات.
- كتلة `@media (prefers-color-scheme: dark)` في `styles.css` دلوقتي ناقصها متغيرات الـ accent والـ badge. لازم تبقى نسخة كاملة من `body.dark-theme`، وتتضاف فيها متغيرات المراحل كمان.
- متغيرات `--badge-*` الحالية تفضل موجودة، وتشاور على متغيرات المراحل المناسبة (green → finished، amber → finishing، red → urgent).

### 4. شكل الكروت والإحصائيات
- كارت الإحصائية: خلفيته `--stage-X-bg`، وحافته `--stage-X-border`، واسمه بلون `--stage-X-text`، والرقم بلون النص العادي (`--text-primary`) ووزن 700.
- كارت "الإجمالي" محايد، من غير لون مرحلة.
- شارة المرحلة على الحالة: نفس الـ bg والـ text بتوع المرحلة.
- الحالة المستعجلة: حافة جانبية بلون `--stage-urgent-solid`.
- الأرقام في الإحصائيات وعدّادات الفلاتر تمر على `| number` في Angular، أو على دالة واحدة مشتركة لو العرض مش من خلال template.

### 5. ترتيب التنفيذ
كل مرحلة لازم تتشاف وتشتغل لوحدها قبل اللي بعدها:
1. **الأساس:** `index.html` و`styles.css`، يعني الخط ومتغيرات المراحل وتصليح كتلة prefers-color-scheme.
2. **الريسبشن:** `secretary.css` (282 لون) وأي HTML لازم classes المراحل.
3. **الطباعة والمسح:** `entry.css` و`station-scan.css`.
4. **الديزاين والفينيش:** `design.css` و`finishing.css` و`case-management.css`.
5. **الأدمن والحسابات:** `admin.css` و`finance-panel.css` و`secretary-dashboard.css`.
6. **بوابة الدكتور:** `doctor*.css` و`for-doctors.css` و`requester.css`.
7. **تسجيل الدخول والمكوّنات المشتركة:** `login.css` و`app-overflow-menu.css` و`brand-lockup.css` و`case-barcode.css` و`tooth-chart.css` و`app.css`.

## القيود
- Angular 20، و standalone components. التعديل في ملفات `.css` وفي `class` بالـ HTML بس.
- لازم الوضعين يشتغلوا: `body.dark-theme` و`body.light-theme` من `theme.service.ts`، وكمان تفضيل الجهاز لو المستخدم ما اختارش.
- مفيش لون مكتوب كرقم في ملفات الشاشات بعد ما تخلص مرحلتها، إلا اللي في `@media print`، والـ `rgba()` الشفافة للظلال، والـ `tooth-chart` لو ألوانه بتمثّل حاجة طبية. ودي يقرر فيها المنفّذ ويكتب السبب.
- الـ build (`ng build`) لازم ينجح بعد كل مرحلة.

## إزاي نتأكد
- بعد كل مرحلة، نفتح الشاشات بتاعتها في المتصفح في الوضعين، وناخد صورة قبل وبعد.
- `grep` على الملفات اللي خلصت ميطلعش ألوان hex برة الاستثناءات.
- صاحب السيستم يشوف الصور ويوافق قبل المرحلة اللي بعدها.

## متروك للمنفّذ
- أسماء الـ classes الجديدة في الـ CSS، طالما ماشية على `stage-<name>`.
- ربط الألوان القديمة بالمتغيرات الجديدة: أي لون قديم يتحوّل لأقرب متغير بمعناه، مش بشكله.
- قيم `solid` ودرجات الـ hover.
